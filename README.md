# ⏰ Digital Clock

A simple and visually appealing **Digital Clock web project** built with HTML, CSS, and JavaScript.

The main purpose of this project is to create a **static website and deploy it using GitHub**. This project was also created and managed using GitHub as a practical way to learn and demonstrate static website hosting.

## 🌐 Live Demo

**GitHub Pages:**
https://jin2das.github.io/Digital-Clock/

## 📌 About the Project

The Digital Clock displays time through a clean and simple web interface. The project uses standard front-end technologies and does not require a backend server or database.

It was created as a learning project to understand:

* Static website development
* HTML, CSS, and JavaScript
* Managing source code with GitHub
* Working with GitHub repositories
* Deploying a static website using GitHub Pages
* Organizing website assets and files

## 🚀 Running the Project Locally

Since this is a static website, no backend setup is required.

### 1. Clone the repository

```bash
git clone https://github.com/Jin2Das/Digital-Clock.git
```

### 2. Open the project

```bash
cd Digital-Clock
```

### 3. Run the website

Open `index.html` directly in your web browser.

You can also use a development extension such as **Live Server** in Visual Studio Code for local development.

## 🌍 Deploying with GitHub Pages

This project can be hosted as a static website using **GitHub Pages**.

### Steps

1. Push the project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, select the appropriate branch, such as `main`.
6. Select the root folder `/`.
7. Save the configuration.
8. GitHub will build and publish the static website.

After deployment, the website can be accessed through the GitHub Pages URL.
